# ShopperStack — QA Testing Portfolio

Manual and API testing work done on **ShopperStack**, an e-commerce web application, as part of a software testing training project at Qspiders, Pune.

## About the Project
ShopperStack is a training e-commerce web application covering core shopping flows: user login, product search, cart, and checkout. This repo documents the QA work performed on it, including test design, execution, defect reporting, and API testing.

## What's in this repo

| Folder/File | Description |
|---|---|
| `/test-cases` | 20+ manual test cases across Login, Product Search, Cart, and Checkout modules, written in a standard test case format (steps, test data, expected result, priority, severity) |
| `/api-testing` | Postman collection used to test ShopperStack's API endpoints — request/response validation, status codes, and environment variables |
| `/bug-reports` | Sample defect reports logged in the same format used in JIRA, with steps to reproduce, expected vs actual behavior, severity, and priority |

## Testing Scope
- **Functional Testing** — verifying core flows (login, search, cart, checkout) behave as expected
- **Regression Testing** — re-testing after fixes to confirm no new defects were introduced
- **API Testing** — validating endpoint responses, status codes, and payloads using Postman
- **Defect Management** — identifying, logging, and tracking bugs through their lifecycle

## Tools Used
Manual Testing · Postman · JIRA (bug tracking format) · SDLC/STLC principles
